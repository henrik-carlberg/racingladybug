Åtgärder vid incidenter Dygnet runt

Har ni drabbats av intrång, ransomware, kapat konto eller misstänkt dataläcka? Vi hjälper er att stoppa angreppet, begränsa skadan och komma tillbaka i drift – och ser till att det inte händer igen.

  • Stoppa angreppet och isolera drabbade system
  • Utreda vad som hänt och vilken data som påverkats
  • Återställa system och data på ett säkert sätt
  • Hjälp med rapportering, t.ex. personuppgiftsincident till IMY
  • Åtgärder som täpper till säkerhetsluckan
